# -----------------------------------------------------------------------
# STEP 1 — install PyTorch FIRST, separately, matching your GPU
# -----------------------------------------------------------------------
# Your GPU (RTX 5060) is Blackwell architecture (compute capability sm_120).
# That requires PyTorch >= 2.7 built against CUDA 12.8+ ("cu128" wheels).
# An older cu121/cu118 build will NOT run kernels on this GPU.
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
#
# Verify afterwards with:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#
# Do NOT put torch in this file — installing it via a plain `pip install -r`
# would pull the CPU-only build from PyPI instead of the CUDA build above.
#
# -----------------------------------------------------------------------
# STEP 2 — then install everything else
# -----------------------------------------------------------------------
#   pip install -r requirements.txt
# =============================================================================
