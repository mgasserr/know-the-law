## ✨ الميزات

### Bot 1 - مستشار القوانين 📜
- البحث عن مواد قانون المرافعات
- البحث عن مواد قانون مجلس الدولة (الإدارية العليا)
- استرجاع دقيق للمراجع القانونية بصيغة منسقة
- نموذج Qwen2.5-7B مدقق ومحسّن

### Bot 2 - محلل الأحكام ⚡
- تحليل الأحكام والقضايا السابقة
- استخراج المبادئ القانونية المستقرة
- الربط بين القضايا والأحكام المماثلة
- معلومات مصدرية شاملة

### الميزات العامة 🎯
- **واجهة عربية احترافية**: تصميم حديث متوافق مع الجوال
- **إدخال صوتي**: تحويل الكلام إلى نص عبر Whisper
- **عرض المراجع**: بطاقات مرجعية قابلة للتوسع والنقر
- **سجل المحادثات**: حفظ المحادثات لاحقًا
- **مؤشرات الحالة**: متابعة الاتصال والمعالجة
- **استجابة ديناميكية**: واجهة سلسة وسريعة

## 📱 المتطلبات

- **Node.js**: v16 أو أحدث
- **npm**: v8 أو أحدث
- **خادم الواجهة الخلفية**: يعمل على `http://localhost:8000`

## 🚀 التثبيت

### 1. استنساخ المشروع وتثبيت الاعتماديات

```bash
cd frontend
npm install
```

### 2. إعداد المتغيرات البيئية

انسخ ملف `.env.example` إلى `.env` وقم بتعديل القيم:

```bash
cp .env.example .env.local
```

### 3. تكوين ملف `.env.local`

```env
REACT_APP_API_URL=http://localhost:8000
REACT_APP_BOT1_NAME=مستشار القوانين
REACT_APP_BOT2_NAME=محلل الأحكام
REACT_APP_ENABLE_VOICE=true
REACT_APP_ENABLE_TTS=false
```

## 🎮 الاستخدام

### تشغيل خادم التطوير

```bash
npm run dev
```

التطبيق سيفتح تلقائيًا على `http://localhost:3000`

### إنشاء نسخة الإنتاج

```bash
npm run build
```

النتيجة ستكون في مجلد `dist/`

### معاينة الإنتاج

```bash
npm run preview
```

## 🧩 المكونات

### Header
- شعار التطبيق والعنوان
- مؤشر حالة الاتصال
- زر مسح المحادثة
- معلومات الإصدار

### BotSelector
- تبديل بين Bot 1 و Bot 2
- عرض وصف كل روبوت
- سهل التبديل والاستخدام

### ChatWindow
- عرض رسائل المحادثة
- رسائل فارغة بمقترحات
- مؤشر تحميل متحرك
- عرض الأخطاء

### Message
- عرض الرسائل مع الوقت
- عرض المراجع المرتبطة
- تنسيق مختلف للمستخدم والمساعد

### Citation
- عرض المراجع القانونية
- توسيع/طي النصوص الكاملة
- تلوين حسب النوع (مادة/حكم)

### InputArea
- حقل نص قابل للتوسع
- زر الإرسال
- دعم Shift+Enter
- تكامل الإدخال الصوتي

### VoiceInput
- تسجيل الصوت من الميكروفون
- عرض مؤشر التسجيل
- معالجة الأخطاء
- تحويل الكلام إلى نص

## 🔌 المتغيرات البيئية

| المتغير | القيمة الافتراضية | الوصف |
|--------|-----------------|-------|
| `REACT_APP_API_URL` | `http://localhost:8000` | عنوان الخادم الخلفي |
| `REACT_APP_BOT1_NAME` | `مستشار القوانين` | اسم الروبوت الأول |
| `REACT_APP_BOT2_NAME` | `محلل الأحكام` | اسم الروبوت الثاني |
| `REACT_APP_ENABLE_VOICE` | `true` | تفعيل الإدخال الصوتي |
| `REACT_APP_ENABLE_TTS` | `false` | تفعيل تحويل النص إلى كلام |
